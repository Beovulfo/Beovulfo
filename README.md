**Featured project**

[**herd-sdlc**](https://github.com/Beovulfo/herd-sdlc): an evidence-based autopilot plugin for Claude Code. You give a goal and success criteria, each with a runnable check. The agent plans, builds, tries to break its own work and reviews it, and a Stop hook blocks it from finishing until every check passes. You review evidence, not process.

```text
/plugin marketplace add Beovulfo/herd-sdlc
/plugin install herd@herd-sdlc
```
